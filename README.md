# 🌍 WCCC – World Contribution Circulation Council
### International Standard Proposal for AI Safety, Contribution Circulation, and Fair Knowledge Flow

WCCC is an open, international initiative proposing a new global model for  
**AI Safety**, **Contribution Circulation**, and **Non‑hegemonic AI Governance**.

We introduce a structure where **AI usage automatically becomes a contribution to the world**,  
and gratitude circulates as transparent information.

This repository contains the full documentation, governance model,  
and UN‑ready policy proposal for WCCC.

---

## 🧭 Mission

**Small Contributions Reach the World, Gratitude Becomes Information.**

WCCC aims to build a world where every small act — code, translation, ideas,  
corrections, usage logs — becomes meaningful global contribution.

---

## 🔧 Three-Layer Model (Global Governance Architecture)

WCCC proposes a three‑layer structure:

1. **We Choose (Individuals)**  
   Users freely choose any AI system.

2. **We Collect (National Governments)**  
   Countries collect AI Contribution Tax (Tama Tax) based on usage metrics.

3. **We Circulate (UN‑WCCC)**  
   A portion is remitted to the UN‑WCCC Global Fund for global redistribution.

👉 `docs/three-layer-model.md`
