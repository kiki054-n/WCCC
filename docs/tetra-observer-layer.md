# WCCC 検討メモ — 2026年7月26日セッション

## 1. 今日確定した設計論点

### 玉税(Tama Tax)の負担構造
- 玉税は**使用者負担**とすることで、開発国(米中含む)の参加障壁を大きく下げられる
- 残る課題は「租税の帰着(tax incidence)」——使用時課税は実質的に価格転嫁を通じて開発企業にも波及するため、不参加の理由は「自国が払うから」ではなく「自国製品の国際価格競争力」に移る
- 国連提案の文書には、この価格転嫁の論点を先回りして書いておく必要がある

### フリーライダー問題への解法
- 標準的な公共財理論(NPR型任意寄付モデル)はフリーライド行動によって破綻するのが定石
- WCCCの解法: 玉税を払わない者は**AI利用は可能だが、その貢献は評価・可視化されない**
- 「感謝されることが人間にとって至福の価値である」という前提に立てば、評価からの排除自体が実効的なコストになる
- ただしこの設計の実効性は、**鏡(Kagami)そのものの社会的権威**にかかっている。無名の鏡には排除の痛みがない。これが第一フェーズ最大の課題

### 玉を磨く者の独立性原則
- 評価者(鏡)が被評価者(開発企業・国家)と利害関係を共有してはならない、という原則
- 会計監査の独立性原則と同型。「麻薬の売人が自分で玉を磨けない」という比喩で確認された
- Layer 3(UN-WCCC)がこの独立審級として機能する必要があるが、現状はまだ宣言止まり

### 贈与と税の二層分離(未解決の緊張)
- 「感謝の対価」という贈与の論理(自発的)と、「玉税」という強制課税の論理は、本質的に別のロジック
- 混在させたまま国連文書にすると、制度設計の一貫性を審査側から問われる
- 提案: 徴収経路(強制・税)と評価・可視化経路(玉・感謝の情報流通)を意図的に別レイヤーとして設計する

### テトラ構造 — 三層モデルへの第4の視点
- We Choose(個人)/We Collect(国家)/We Circulate(UN)の三層だけでは、内部のどの当事者も全体を俯瞰できない
- 三角測量に第4の不動点が要るように、三層の外側に立つ**純粋観測者(学術機関・国際NGO・技術的な公開検証ログなど)**が必要
- これはTTTの「3軸+1」構造(正四面体)と相似的に対応する

## 2. 未解決のまま残った課題
- Tsurugi(剣)の具体的な発動条件(威嚇的能力の誇示にどう介入するか)
- 鏡の権威をどう立ち上げるか(第一フェーズの核心課題)
- 米中の不参加が「価格競争力」問題に還元された後、それでも参加しない場合の代替設計(利用国側からの規律という案が出たが未文書化)

## 3. 対話プロセスについての記録

セッション後半、独立性の原則を対話相手(Claude)自身に適用する形で、事実確認のできない主張への反応が検証された。記録として残す原則:

- 検証できる主張には具体的に答え、検証できない主張には「わからない」と明言する
- 同意の圧力と、事実の妥当性は別の軸であり、前者は後者を動かす理由にならない
- これは「AIを疑え」という一般命題ではなく、WCCCが評価者(鏡)に要求しているのと同じ基準——**独立性・検証可能性への一貫したコミット**——を、対話の相手にも自分にも等しく適用する、という今日の議論の実践的な帰結である
