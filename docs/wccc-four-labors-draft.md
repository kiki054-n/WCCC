# 四つの労働とTama循環 — 著作権が届かない領域をWCCCはどう捕捉するか

## 1. AI社会参入による労働の四分類

AIの社会実装が進むほど、人間労働は次の四つに再編されると考えられる。

1. **生産労働** — 製造、物流、農業など、AIやロボティクスによる自動化が進む物理的生産
2. **介護ケア労働** — 対人ケア、育児、介護など、身体性・関係性ゆえに自動化が困難な労働
3. **管理労働** — 公務員、行政、制度運用など、ルールに基づく判断・調整業務
4. **創造労働** — アニメーション、音楽、文章、デザインなど、著作物を生む労働

WCCCの既存の枠組み(BFOL、玉税)は主に4の**創造労働**を想定して設計されてきた。しかし現実の搾取構造は、著作権の枠組みそのものが対象にしていない領域で先鋭化している。

## 2. 著作権が捕捉できない二つの搾取

### 2.1 創造労働内部の搾取 — アニメーター等の実制作労働

著作権は「作品」を保護するが、**作品を成立させる個々の労働工程**は保護しない。日本のアニメーション制作では、原画・動画工程の従事者が出来高制の低賃金で働く構造が長年指摘されてきた。作品がヒットしてライセンス収益を生んでも、その利益は制作委員会・版権元に集中し、実制作者への還流はほぼ設計されていない。著作権法は「誰が権利者か」を定めるが、「誰が実際に価値を作ったか」の分配は関知しない。

### 2.2 「AIティーチング労働」— 著作権制度がそもそも想定していない労働

これはさらに深刻な、**制度の外側にある**問題である。生成AIの性能向上は、次のような労働に支えられている。

- **RLHF(人間フィードバックによる強化学習)**のためのラベリング・評価作業
- **有害コンテンツのモデレーション**(暴力的・性的な出力を人間が判定し除去する作業)
- 一般利用者による**訂正・修正・良し悪しの評価**(利用者が意図せず提供している教師データ)

2023年に報じられたOpenAIの事例では、ケニアの外部委託労働者が低賃金かつ有害コンテンツへの曝露を伴う条件でモデレーション作業に従事していたことが明らかになっている。この労働は:

- 著作物を生んでいないため著作権の対象にならない
- 雇用契約上「AIの一部を作った」という認識を労働者にも社会にも与えられていない
- 利用者自身が無自覚に提供している訂正・評価データに至っては、労働として認識すらされていない

つまり、創造労働の搾取が「権利はあるが分配されない」問題だとすれば、AIティーチング労働の搾取は**「労働として認識されてすらいない」**、より根の深い問題である。

## 3. WCCCがこの領域を捕捉できる理由

WCCCの玉(Tama)循環モデルは、著作権のように**「誰が権利者か」を起点に設計されていない**。起点は「AI利用というトークン量として計測可能な行為」であり、これは以下を意味する。

- 著作物の有無に関わらず、**AIの性能向上に寄与した行為を、鏡(Kagami)によって記録・可視化できる**構造上の柔軟性がある
- RLHFやモデレーション労働を、BFOLの「Tama Clause(貢献の還流)」における**還流対象労働**として明示的に位置づければ、著作権が届かない領域を玉税の再分配設計でカバーできる
- アニメーターのような実制作労働についても、「作品の権利者」ではなく「**AI学習・生成過程に寄与した工程労働者**」として玉の分配対象に加えることが、著作権法の改正を待たずに可能

## 4. 提案する追記構造

`docs/bfol-license.md` のTama Clauseに、還流対象として以下を明示的に追加することを提案する。

- 創造労働: 実制作工程労働者(原画・動画・アシスタント等)への直接還流枠
- AIティーチング労働: RLHF・モデレーション・データラベリングの外部委託労働者への還流枠
- 無自覚教師データ提供: 利用者の訂正・評価行為が学習に利用された場合の、匿名集計ベースでの還流(個人特定なしのプール分配)

これにより、WCCCは「著作権が保護する創作物の分配」ではなく、**「AIの価値を実際に作った行為全体の分配」**という、より広い射程を持つ枠組みとして位置づけられる。

## 未解決の課題

- 工程労働者への還流を、制作委員会・発注元を介さずにどう技術的に補足するか(下請け構造の不透明性)
- 「無自覚な教師データ提供」をどう定量化するか、プライバシーとの兼ね合い
- 管理労働・介護ケア労働については、AIによる代替・補助が今後どう玉循環と接続しうるか、現時点では未検討
